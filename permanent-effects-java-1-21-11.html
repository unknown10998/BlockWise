How to give a long-lasting status effect

In Java Edition, use /effect give with a duration in seconds. A very large duration makes an effect last a long time, but it is still a duration—not a permanent server rule.

Example command

/effect give @s minecraft:speed 1000000 1 true

This gives the executor Speed II for 1,000,000 seconds and hides particles. The amplifier is zero-based: 0 is the first level, so 1 displays as Speed II.

Change the effect safely

Replace minecraft:speed with a valid Java effect identifier such as minecraft:night_vision, minecraft:haste, or minecraft:resistance. Use a smaller duration while testing so you can confirm the target and strength.

Remove it

/effect clear @s minecraft:speed

Use the matching identifier to remove one effect, or use /effect clear @s only when you intend to remove all effects from that target.
