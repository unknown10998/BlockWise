06 / COMMANDS

Before you run a command

Open chat and start with /. Single-player worlds need commands/cheats enabled; servers require permission from the owner or operator. Bedrock cheats disable achievements for that world. Never use commands to bypass a server's rules or permissions.

Selectors: @s is the executor, @p nearest player, @a all players, @e all entities, and @r a random player. Use coordinates as absolute values, relative values such as ~5, or local values such as ^ ^ ^3 where supported.

Take care: /clear, /kill, and large /fill operations can affect many entities or erase builds.
