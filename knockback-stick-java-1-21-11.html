How to get a custom Knockback stick

Use a minecraft:enchantments data component on a stick. This is Java syntax; it is not a Bedrock command.

Command

/give @s minecraft:stick[minecraft:enchantments={"minecraft:knockback":255}] 1

Open chat in a world with commands enabled, then run the command. Replace @s with a permitted target selector only when you understand who it affects.

What the number means

The number is the Knockback enchantment level in the component. BlockWise's Java 1.21.11 command helper accepts values from 1 to 255. High custom values are outside normal survival enchanting limits and can be disruptive on shared worlds, so use them only where the world owner allows it.

Common mistakes

  • This command uses Java Edition's component syntax, not older item-NBT examples.
  • Do not paste it into Bedrock Edition; BlockWise intentionally does not generate a Bedrock equivalent.
  • Servers can block commands or restrict permissions even when the syntax is valid.
