Minecraft give diamonds command (Java 1.21.11)

To give yourself a full stack of diamonds, use Minecraft's /give command with the diamond item ID and a quantity of 64.

Command to copy

/give @s minecraft:diamond 64

@s targets you when you execute the command as a player. minecraft:diamond is the Java item identifier. 64 is the amount; use another positive quantity if you need fewer or more items.

How to use this command

Open Minecraft chat, paste the command above, and press Enter. Check the target selector and the selected item or effect before running it. The command does not run automatically from this website.

How to undo it

When relevant, use the following separate command carefully:

/clear @s minecraft:diamond

Enable commands/cheats in a single-player world or obtain appropriate operator permission on a server. /give grants items rather than obtaining them through survival gameplay. The optional /clear command removes diamonds from the target's inventory, so do not run it unless intended.
