How to keep inventory after death

Set the world's keep-inventory gamerule to true. You need commands enabled in single-player or permission from the server owner.

Enable the gamerule

/gamerule minecraft:keep_inventory true

The rule affects the world where you run it. It does not give you server permissions, and a server can have plugins or other rules that change death behavior.

Turn it off again

/gamerule minecraft:keep_inventory false

Before changing a shared world, agree with the people who play there. Keep inventory can make exploration less punishing, but it also changes the risk and recovery loop of survival.

Java and Bedrock are not interchangeable

This page is for Java Edition 1.21.11, whose gamerules use namespaced registry IDs. Bedrock uses a different command grammar and rule naming convention. Select the right edition in BlockWise before copying a command.
