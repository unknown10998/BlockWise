Minecraft infinite night vision command (Java 1.21.11)

Use the /effect give command to turn on night vision with an infinite duration, then remove it when you no longer need it.

Command to copy

/effect give @s minecraft:night_vision infinite 0 true

@s selects you when you run the command as a player. minecraft:night_vision names the effect, infinite keeps the effect running, 0 is the first amplifier level (Night Vision I), and true hides effect particles.

How to use this command

Open Minecraft chat, paste the command above, and press Enter. Check the target selector and the selected item or effect before running it. The command does not run automatically from this website.

How to undo it

When relevant, use the following separate command carefully:

/effect clear @s minecraft:night_vision

Commands require cheats or operator permission. Java uses the /effect give syntax; Bedrock uses a different command format. Night vision can still be cleared by commands, death, or other game mechanics; infinite is not an immunity guarantee.
